This example shows how free space is distributed around the whole grid (the tracks), not inside each grid cell. justify-content: center; centers the set of columns on the inline axis, and align-content: space-between; distributes the rows on the block axis. The container needs to have extra space for these properties to have an effect, so the grid container has a fixed height in this example.
