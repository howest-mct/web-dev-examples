SVG vs raster images

This is an example of the same image in two different formats. The first one is an SVG, which is a vector format, and the second one is a JPEG, which is a raster format. The SVG image will look sharp at any size, while the JPEG image may become pixelated when scaled up. Try zooming in on the page to see the difference between the two images.
