Margin Collapsing Examples

1. Adjacent Siblings (Vertical Margins Collapse)

Box 1 has margin-bottom: 30px
Box 2 has margin-top: 20px
Result: 30px gap (not 50px). Margins collapse to the larger value.

2. Parent and First/Last Child

Child has margin-top: 40px
Parent has margin-top: 20px
Result: Margins collapse through parent

3. Preventing Collapse with Padding or Border

Parent has padding/border
Child margin no longer collapses

4. Preventing Collapse with flow-root

Parent has display: flow-root
Creates new block formatting context
Child margin no longer collapses (no padding/border needed)
