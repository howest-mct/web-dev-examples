CSS Reset Demonstration

This page demonstrates the reset styles applied to common HTML elements.

Typography

Notice how all elements have consistent line-height (1.5) and use the sans-serif font family set in the reset.

  • No default margins on elements
  • Consistent font across all elements
  • All elements use box-sizing: border-box

Responsive Images

Images are set to display: block and max-width: 100%, making them responsive by default.

Box Sizing

This box is 200px wide including padding and border thanks to box-sizing: border-box
