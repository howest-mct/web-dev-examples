Rem vs Em

This example shows how em is relative to the parent font size, while rem is relative to the root (html) font size.

Em (relative to parent)

Parent text size is 2rem.
Child text size is 1.5em, so it becomes 1.5 * 2rem = 3rem.

Rem (relative to root)

Parent text size is 2rem.
Child text size is 1.5rem, so it stays tied to the root size.
